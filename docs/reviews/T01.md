4. [minor] 測試補強：
   - 未知列舉值旁放**非預設**的兄弟欄位，證明只重置該欄位：`{"look":{"theme":"plasma","palette":"ember","mirror":true,"windowMode":"glass","opacity":0.5},"menubar":{"style":"wave","count":5,"colored":true}}` → 只有 theme/windowMode/style 回預設，其他保留。

   - 契約一致性：`PublicAPITests` 加 `requireSendable` 檢查 `SpectrumFrame`、`VisualizerConfig` 與四個列舉；用一個持有 `weak var source: (any SpectrumSource)?` 的 box 確認 `SpectrumSource` 是 class-bound。
